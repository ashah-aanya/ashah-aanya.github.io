AIMon · 2025

An automated re-prompting loop that let 3–7B-parameter models beat GPT-4o on the benchmarks I built it against.

python · llm-eval · rag · together-ai

Open-sourced two 1K+ sample MIT-licensed eval datasets, then productized the loop inside AIMon’s Python SDK as a plug-and-play module for any black-box LLM or RAG system. Wrote the launch blog, the design docs, and the Colab demos.

Agentic yearbook composer in progress

Rethink Yearbooks · 2025–

An agentic system that turns thousands of raw photos into finished yearbook pages — recognizing people, clustering moments, assembling a year’s narrative.

python · agents · deepface · clustering

Grew out of a facial-recognition pipeline I built first: fine-tuned DeepFace over a 10K+ image set to match roster photos to candids and sort them by grade, with a small interface for reviewing matches by cosine distance. The agentic layer on top handles event recognition, clustering images into moments, and laying out finished pages.
